Why vte::Perform vs. Manual ANSI Parsing

vte is a zero-allocation VTE/ANSI state machine used in production by both Alacritty and WezTerm. It correctly handles:

  • Multi-byte UTF-8 characters accumulated before print() is called
  • Escape sequence interleaving and partial-sequence cancellation
  • All ECMA-48 dispatcher hooks: print, execute, csi_dispatch, esc_dispatch, osc_dispatch, hook, put, unhook
  • Edge cases in param parsing (sub-params, default 0 values, overflow)

Rolling a manual parser would require re-implementing the same state machine and would almost certainly miss edge cases. Using vte keeps GridPerformer focused on terminal semantics rather than parser mechanics.

Out of Scope (Deferred)

  • 256-color SGR: 38;5;n / 48;5;n — sub-param sequences, deferred
  • RGB SGR: 38;2;r;g;b / 48;2;r;g;b — deferred
  • DEC private modes: ?25h/l (cursor hide/show), ?1049h/l (alt screen) — deferred
  • Scrolling: When cursor reaches the last row on LF, the grid currently clamps (stays). Scroll region (DECSTBM) and scroll-up not yet implemented.
  • Line wrap: When cursor reaches the last column after print, it clamps. Soft-wrap deferred.
  • Tab stops: HT (0x09) not handled.
  • Erase sequences: ED (erase display), EL (erase line) — deferred.

Reviewer Checklist

  • CHECK 1-based ANSI to 0-based conversion in CSI H: row = param - 1, col = param - 1. ANSI spec says "CSI 1;1H" is home (top-left), not "CSI 0;0H". The implementation subtracts 1, but also guards against 0 params (treats 0 as 1 per spec).
  • CHECK Cursor bounds: clamp vs. wrap: After printing at the last column, cursor is clamped to cols - 1, not wrapped to next line. This is intentional for v0.1 — wrapping requires knowing whether the line is "soft-wrapped" vs. hard-newline for reflow. Deferred.
  • NOTE SGR reset (code 0) restores BOTH fg AND bg to defaults: Verified by sgr_reset_restores_defaults test. A common bug is only resetting fg.
  • NOTE gunter-core::grid is on feat/v0.1-term branch: The grid agent is implementing Grid/Cell in parallel on feat/v0.1-grid. The API in this branch is intentionally identical to the spec. Merge should be clean.
  • NOTE CellFlags uses bitflags manually: Did not pull in the bitflags crate to keep dependencies minimal. Consider switching if more flags are added.
