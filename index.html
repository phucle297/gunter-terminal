Version Roadmap

7 versions from headless PTY to v1.0 public release. Each version is a shippable demo milestone, not a task list.

v0.1.0 Headless PTY Shell not started
PTY → VTE → Grid pipeline. No window. Print grid to stdout. Validates that ANSI parsing and cell state work before any GPU work.
gunter-core gunter-term gunter-app
v0.2.0 GPU Window not started
wgpu surface + winit window. Glyph atlas (wezterm-font). Render single PTY pane at 60fps with Atom One Dark + ComicShannsMono.
gunter-renderer gunter-app
v0.3.0 Interactive Terminal not started
Full keyboard event → PTY write pipeline. Mouse click, resize handling. Usable as a single-pane terminal.
gunter-input gunter-core gunter-app
v0.4.0 Multiplexer not started
Binary layout tree. Pane splits (Ctrl+Shift+H/V), tabs (Ctrl+Shift+T/W), pane cycle (Ctrl+Tab), zoom (Ctrl+Z). Core tmux-style UX.
gunter-core gunter-input gunter-renderer
v0.5.0 Multi-Shell + Socket not started
PowerShell, CMD, any shell via config. Unix socket / Windows named pipe server. `gunter attach <id>` works.
gunter-core gunter-app
v0.6.0 Config + Hot Reload not started
Full TOML config at ~/.config/gunter/config.toml. notify-based hot-reload. Theme system. Font fallback chain (Nerd Font, CJK, emoji).
gunter-core gunter-app gunter-renderer
v1.0.0 Production Release not started
Input latency <10ms, throughput 100 MB/s. Scrollback UX, copy/paste (OSC 52), full mouse support. Windows installer. Public release.

Key Technical Decisions

Each choice over its next-best alternative. Full rationale in linked docs.

GPU Backend
wgpu
DX12+Vulkan in one codebase. WSL2 GPU-PV compatible. Safe Rust API. vs OpenGL (deprecated on macOS) and softbuffer (CPU-only).
VT Parser
vte
Zero-alloc. Same crate used by Alacritty. Zero runtime allocations in the hot path. vs termwiz (heavier, pulls wezterm-mux).
PTY Abstraction
portable-pty
Only Rust crate handling ConPTY (Windows) correctly. WSL2 shell requires ConPTY. No alternative.
Font / Glyph Atlas
wezterm-font
Handles Nerd Font PUA glyphs, font fallback, shaping. fontdue alone can't do fallback; FreeType bindings = weeks of work.
Async Runtime
tokio
PTY read + config watch + socket server all need async. Largest ecosystem. vs async-std (less maintained).
Config Format
TOML
No comments problem (JSON). No indentation footguns (YAML). No runtime (Lua). Already used by Cargo — users know it.
Layout Model
Binary split tree
Same as i3/tmux. Resize reflow is O(depth). Two-level (tab→pane) vs tmux's three-level (session→window→pane) is simpler.
Draw Call Strategy
Instanced draw
Collapses 11,000 cell draws to 1 GPU call. Geometry shaders deprecated in Metal. Compute-shader approach adds barrier complexity for no gain at this scale.

Default Keybindings

ℹ All defaults are conflict-free with readline/shell shortcuts. Only Ctrl+Z conflicts (SIGTSTP) — documented in default.toml. See docs/04-ux-config.md §4 for full rationale.
Tabs & Panes
All Ctrl+Shift bindings to avoid shell conflicts
Ctrl+Shift+T New tab Matches kitty. No readline conflict.
Ctrl+Shift+W Close pane / tab Matches kitty. Avoids kill-word conflict.
Ctrl+Shift+H Split horizontal (side-by-side) H = horizontal layout growth
Ctrl+Shift+V Split vertical (stacked) V = vertical layout growth
Ctrl+Tab Focus next pane Universal next-tab muscle memory. No shell conflict.
Ctrl+Shift+Tab Focus previous pane Universal prev-tab. No shell conflict.
Ctrl+Z Zoom / unzoom pane ⚠ Conflicts with SIGTSTP. Rebind if you use fg/bg.
